# UART protocol implementation

The directory [`imports/temp`](./imports/temp) has been replicated from Anas Salah Eddin's github [repository `ece_3300`](https://github.com/aseddin/ece_3300/),
and specifically this [directory](https://github.com/aseddin/ece_3300/tree/main/M12%20UART/Source).
It has not been replicated one-to-one.

Unfortunately, the author, Anas Salah Eddin, hasn't provided a license to go with it.
However, since he links to it from his YouTube courses, where he explicitly mentions his GitHub, and verbally agrees to "educational" use
of his code as seen [here](https://www.youtube.com/watch?v=s9EWwXjg70o) within the first 30 seconds, I have merely followed his instructions
in my use of his code.
Note: I am using a GPLv3 license.
